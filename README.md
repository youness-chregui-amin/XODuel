#  Project Overview

XO Duel is a desktop implementation of the classic Tic-Tac-Toe game developed using **C#**, **.NET Framework**, and **Windows Forms**.

The project focuses on creating an interactive game with clean game logic, responsive user interface, and smooth gameplay while practicing Object-Oriented Programming and Event-Driven Programming.

---

#  Features

## 🎲 Gameplay

- Two-player local gameplay
- Automatic turn switching
- Visual turn indicator
- Winner detection
- Draw detection
- Winning line highlighting
- Invalid move prevention

##  User Interface

- Pixel-art design
- Custom X and O images
- Dynamic player colors
- Winner color indication
- Game Over notification
- Exit confirmation dialog

## 🔄 Game Management

- Restart the game at any time
- Reset the game board
- Reset player turns
- Reset game status

#  How to Play

1. Launch the game.
2. Player 1 starts with **X**.
3. Player 2 plays with **O**.
4. Players take turns selecting an empty square.
5. The first player to align three symbols horizontally, vertically, or diagonally wins.
6. If all squares are filled without a winner, the game ends in a draw.
7. Click **Restart** to begin a new match or **Exit** to close the game.
